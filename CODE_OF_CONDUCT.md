# Code of conduct

We want Security Kit to be a welcoming project for everyone.

- Be respectful and constructive. Critique ideas and code, not people.
- Assume good intent, and help newcomers.
- No harassment, discrimination, or personal attacks — in issues, pull requests, discussions or anywhere else
  related to the project.

Maintainers may remove comments or contributions, or block participants, that break these rules. Report problems
privately to the maintainers through the contact listed on the repository.

This code of conduct is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
